## [1.0.0] — 2026-09-29

### Добавлено
- **Консольный скрипт** `Check-RdpPatch.ps1`:
  - Автоопределение ОС по `BuildNumber` через `Win32_OperatingSystem`.
  - Разделение карт патчей на серверные и клиентские редакции.
  - Проверка наличия проблемного обновления и исправления через `Get-HotFix`.
  - Вердикт по трём сценариям: «не затронута» / «защищена» / «требуется установка».
  - Автогенерация ссылки на Microsoft Update Catalog.
  - Параметр `-OpenLink` для открытия ссылки в браузере.

- **GUI-версия** `Check-RdpPatch-GUI.ps1` (WinForms):
  - Окно 720×580 с заголовком и подзаголовком.
  - Цветовая подсветка вердикта (зелёный / красный).
  - Поле **Download link** с URL каталога Microsoft.
  - Кнопка **Copy link** — копирование URL в буфер обмена с подтверждением.
  - Кнопка **Open in browser** — открытие ссылки по умолчанию.
  - Кнопка **Re-check** — перезапуск проверки.
  - Кнопка **Close** — закрытие окна.
  - Кнопки ссылки деактивируются, если патч не требуется.

- **Скрипт сборки** `build-exe.ps1`:
  - Автоустановка модуля `ps2exe` при отсутствии.
  - Автоопределение версии из `CHANGELOG.md`.
  - Поддержка иконки (`icon.ico`).
  - Метаданные EXE: Title, Company, Product, Version, Copyright.
  - Цветной вывод с пошаговыми статусами.
  - Ключ `-SkipInstall` для пропуска установки модуля.

- **Документация**:
  - `README.md` с описанием проблемы, поддерживаемых ОС, инструкциями по запуску и сборке.
  - `CHANGELOG.md` (этот файл).

### Поддерживаемые ОС
- **Серверные**: Windows Server 2012, 2012 R2, 2016, 2019, 2022, 2025.
- **Клиентские**: Windows 10 (1507–22H2, LTSC 2015/2016/2019), Windows 11 (21H2–26H1).

### Известные ограничения
- Поддержка Windows Server 2012 / 2012 R2 в GUI пока не реализована (в консольной версии работает).
- Ссылки на `.msu` в каталоге Microsoft — динамические, не сохраняются.
- EXE, собранный через PS2EXE, может блокироваться SmartScreen и антивирусами.

## Как вести CHANGELOG

1. **Новые изменения** — в секцию `[Unreleased]`.
2. **При релизе** — создаётся новая версия по SemVer:
   - `MAJOR` — несовместимые изменения.
   - `MINOR` — новая функциональность обратно совместимая.
   - `PATCH` — исправления обратно совместимые.
3. **Категории** изменений:
   - **Добавлено** — новый функционал.
   - **Изменено** — изменения существующего поведения.
   - **Устарело** — что будет удалено.
   - **Удалено** — что удалено.
   - **Исправлено** — фиксы багов.
   - **Безопасность** — правки в части безопасности.
4. **Дата релиза** — в формате `YYYY-MM-DD`.
