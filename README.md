🚀 Как использовать

    Сохраните скрипт как Check-RdpPatch.ps1 (например, в D:\Repo\Omnissiah_Toolbox\scripts\).

    Запустите на целевом сервере (локально или через Enter-PSSession):
    powershell

    .\Check-RdpPatch.ps1

    С автоматическим открытием ссылки в браузере, если патч отсутствует:
    powershell

    .\Check-RdpPatch.ps1 -OpenLink
